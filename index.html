Binary success labels cannot tell a clean execution from one where the object slips or the box is shoved. SPECTRA learns the admissible variation of relative object poses from successful demonstrations and assigns every new execution a continuous quality score Q ∈ [0, 1].

Abstract

Robotic manipulation is usually judged by a binary success label, yet two successful executions can differ widely in how precisely they were carried out. SPECTRA learns task-specific kinematic constraints from a small set of successful demonstrations: the directions of relative object motion that stay consistently regulated, and how much each may vary. New executions are scored by how well they respect these constraints, yielding a single, interpretable quality index that is robot-agnostic and needs no human labels.

How It Works

Constraint estimation: demonstrations are aligned by sub-task progress, and relative object poses are compared in the tangent space of SE(3). Directions with little variation across demonstrations are marked as constrained. Policy evaluation: a new execution is penalized only when it drifts beyond the learned tolerance along those directions.

Pinpointing What Went Wrong

Every frame of an execution gets a cost, so SPECTRA shows not only how well a task was done but when it went wrong. Here, an execution that still succeeds is scored Q = 0.46 because of deviations during the lift and place phases.
